# CCSync+ — releases

Signed macOS builds of **CCSync+**, the menu-bar app for people who use Claude on more than one account or more than one Mac: one-click account switching across Terminal/VS Code and Claude Desktop, encrypted backup & restore, sync across Macs.

- **Install:** download the newest `.zip` from [Releases](../../releases), unzip, drag `CCSync+.app` to Applications.
- **Updates:** installed copies check `latest.json` here and update themselves.
- Free to use. Source is not published; the engineering story is in the owner's APPROACHES document. Not affiliated with Anthropic.
